# A16Probe

Исследовательское приложение на SwiftUI / Objective-C для **iPhone 14 Pro Max
(iPhone15,3, A16)**. Запрошенная конфигурация — **iOS 27.3 beta 1**.
Совместимость с ней пока не подтверждена физическим устройством.

Приложение собирает диагностику, а не выполняет эксплойт:

- читает модель, числовую версию ОС и номер её сборки;
- проверяет наличие публичных методов Foundation;
- проверяет видимость символов ContainerManager и sandbox extension через
  `dlsym`, **не вызывая найденные функции**;
- использует `RTLD_NOLOAD`: не загружает новые приватные библиотеки;
- сохраняет подробный JSON-журнал только в собственном sandbox.

Запросы к ContainerManager, получение/применение sandbox extension, подмена
symlink, перебор inode и чтение чужих контейнеров не реализованы. App Group и
приватные entitlements не требуются. Сетевых запросов нет. Системные файлы не
изменяются. Запись и ротация затрагивают только собственные отчёты приложения.

## Статус проверки

Сборка Swift/Objective-C и unsigned IPA подтверждены в
[Actions run 42536607791](https://github.com/G-P-T4EVER/A16Probe/actions/runs/42536607791):
Xcode 16.4, iOS SDK 18.5, ARM64, minimum OS 16.0. Прошли Swift-тесты
совместимости и Python-тесты валидатора. Скачанный IPA повторно проверен:
структура, CRC, отсутствие подписи и SHA-256 совпали.

Полный лог проверен: ошибок компиляции нет; предупреждение AppIntents сообщает
о пропуске метаданных, поскольку приложение не использует этот framework.
Это проверка сборки, а не работы на iOS 27.3 beta 1. Теста на физическом
устройстве и подтверждения эксплуатации нет.

## Сборка unsigned IPA

Нужен macOS с Xcode 16 или новее, установленным iPhoneOS SDK и Python 3.
Зависимостей CocoaPods/SPM/Homebrew нет.

```sh
./scripts/build_unsigned.sh
```

Скрипт сохраняет версию Xcode/SDK и commit SHA, выполняет тесты классификации
совместимости, тесты валидатора, компилирует Release для `generic/platform=iOS`
с отключённой подписью, упаковывает `Payload/A16Probe.app`, проверяет IPA и
вычисляет SHA-256. Результаты находятся в `build/`.

[GitHub Actions](.github/workflows/unsigned-ipa.yml) запускается на `macos-15`
при push в `main` / `research/**`, pull request или вручную. Используется
установленный на runner Xcode; конкретный SDK 27.3 не предполагается. Минимальная
ОС приложения — iOS 16.0. Сборка старшим или младшим SDK сама по себе не
подтверждает поведение на iOS 27.3 beta 1.

При успешной сборке artifact `A16Probe-unsigned-<SHA>` содержит:

- `A16Probe-unsigned.ipa` и SHA-256;
- `ipa-verification.json` с результатами статических проверок;
- `toolchain.txt` с фактическим инструментарием и commit SHA.

Отдельный artifact содержит логи, в том числе при ошибке сборки. Workflow имеет
только `contents: read`, не использует сертификатов или секретов и не публикует
GitHub Release. Actions закреплены по commit SHA.

Проверить скачанный IPA повторно:

```sh
python3 scripts/verify_ipa.py build/A16Probe-unsigned.ipa
(cd build && shasum -a 256 -c A16Probe-unsigned.ipa.sha256)
```

Проверяются CRC/пути ZIP, единственный ожидаемый app bundle, Info.plist,
исполняемый ARM64 Mach-O для **iOS device**, отсутствие `LC_CODE_SIGNATURE`,
профиля подписи и `_CodeSignature`. ARM64 simulator не принимается. Проверки
не доказывают корректность установки, запуска или доступность приватных API.

## Запуск на устройстве

Unsigned IPA нельзя установить обычным способом без подписи. Для теста откройте
`A16Probe.xcodeproj`, выберите собственную Signing Team и уникальный bundle ID,
подключите iPhone и запустите схему `A16Probe` через Xcode. При необходимости
включите Developer Mode. Проверка IPA в CI ожидает исходный bundle ID
`org.a16probe.research`; изменение ID для локальной подписи не нужно коммитить.

В приложении нажмите «Запустить диагностику». Экспорт JSON становится доступен
только после успешной записи. Файлы находятся в `Documents/A16ProbeReports`,
исключены из backup и защищены до первого разблокирования после загрузки.
Остаются последние 20 отчётов. Удаление приложения удаляет его отчёты.

Журнал содержит временные отметки, длительность этапов, модель, сборку ОС,
проверенные символы и границы проверки. Имя телефона, UDID, адреса функций и
списки чужих файлов не собираются. До экспорта просмотрите JSON; отправка
происходит только через выбранное пользователем действие Share Sheet.

Значения результатов:

| Поле / статус | Значение |
| --- | --- |
| `visible` | Символ разрешён, но не вызван; ABI и доступ к сервису не проверены |
| `notVisible` | Символ не виден в выбранной области поиска; это не доказательство удаления API |
| `notChecked` | Образ не был уже загружен; новую библиотеку не загружаем |
| `numericOSMatch` | Сравниваются только числа 27.3.0 |
| `betaBuildMatch` | Всегда unverified до появления проверенного build ID beta 1 |
| `vulnerabilityStatus` | Всегда notTested: эксплуатации в приложении нет |

Симулятор явно отмечается отдельно и не подтверждает совместимость iPhone.
План физической проверки: [docs/DEVICE_TEST.md](docs/DEVICE_TEST.md).

## Источник исследования

Анализ основан на открытом [forcequitOS/worse_query](https://github.com/forcequitOS/worse_query)
на commit `d1540e20cd82b974d891e0551ced6d6aeb570ac2`. Заявления upstream о поддержке
ОС не являются результатами наших тестов. Реализация PoC и `pathleak` в этот
проект не перенесены. Подробности, ограничения и ссылки:
[docs/CONTAINERMANAGER_ANALYSIS.md](docs/CONTAINERMANAGER_ANALYSIS.md).

## Локальные проверки без macOS

```sh
python3 -m unittest discover -s Tests -p 'test_*.py' -v
bash -n scripts/build_unsigned.sh
git diff --check
```

Swift-тесты запускаются build-скриптом на macOS. Они проверяют различие между
моделью устройства, симулятором, числовой версией и неподтверждённой beta-сборкой.
