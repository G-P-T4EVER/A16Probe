# Проверка на физическом устройстве

Статус: **не выполнена**. Ни устройство, ни подписанная сборка в этой сессии
не были доступны. Этот документ — протокол будущего теста, а не его результат.

1. Зафиксировать commit SHA, результат Actions, SHA-256 IPA и Xcode/SDK из
   `toolchain.txt`. Убедиться, что `ipa-verification.json` относится к этому SHA-256.
2. Записать модель и полный build ID из Settings → General → About.
   Для iPhone 14 Pro Max ожидается `iPhone15,3`. Проверить обозначение beta 1 по
   доверенному источнику Apple, не только по числу `27.3`.
3. Собрать и подписать тот же commit в Xcode собственной командой разработки.
   Отметить изменения bundle ID/подписи. Установить и запустить на телефоне.
4. Нажать «Запустить диагностику». Проверить отзывчивость экрана, отсутствие
   аварийного завершения и появление «Отчёт сохранён».
5. Экспортировать JSON. Сверить hardwareIdentifier, osBuild, osVersion,
   `simulator: false`, временные отметки и события. Все флаги вызова приватных
   функций должны оставаться false. `notChecked`/`notVisible` допустимы.
6. Повторить запуск, проверить новый runID. После 21 запуска убедиться через
   контейнер приложения в Xcode, что осталось 20 JSON. Ротация касается только
   `Documents/A16ProbeReports`. Проверить экспорт через Share Sheet и отмену экспорта.
7. Проверить отдельно симулятор и другое устройство/версию, если доступны:
   несовпадение должно явно отражаться в отчёте, без заключения об уязвимости.
8. Записать наблюдения и ошибки ниже. Не отмечать эксплуатацию успешной:
   этот диагностический инструмент не выполняет её.
