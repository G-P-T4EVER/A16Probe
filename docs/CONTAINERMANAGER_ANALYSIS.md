## Наблюдаемый механизм

Upstream работает с App Group, принадлежащей приложению. Он динамически
разрешает приватные функции ContainerManager, меняет разрешение пути
подкаталога App Group через символическую ссылку и отправляет запрос сервису.
Затем получает sandbox-extension token из результата и применяет его в
процессе. Существенная граница доверия — соответствие логического контейнера,
разрешённого пути и полномочий выдаваемого расширения sandbox.

Отдельный `pathleak.m` перечисляет пути через перебор inode. Такой перебор
не нужен для наблюдения API и в A16Probe отсутствует. A16Probe не воспроизводит
последовательность эксплуатации, числовые параметры запросов или тесты
доступа к чужим данным.

## Что проверяет A16Probe

| Проверка | Наблюдение | Чего она не устанавливает |
| --- | --- | --- |
| `hw.machine`, версия ОС, `kern.osversion` | Идентификатор модели и фактическая сборка | Beta 1 без эталонного build ID |
| `respondsToSelector:` | Наличие публичного метода Foundation | Наличие прав App Group или успешный вызов |
| `dlopen(..., RTLD_NOLOAD)` | Уже загруженный образ ContainerManager доступен | Возможность загрузить его или доступность сервиса |
| `dlsym` для семейства `container_query_*` | Видимость экспортированного имени | Сигнатуру, ABI, поддержку параметров или выполнение запроса |
| `dlsym` для token/extension API | Видимость символов | Получение токена, права или обход sandbox |

Для `sandbox_extension_*` область поиска — `RTLD_DEFAULT`; для ContainerManager —
handle уже загруженного образа. Поиск через handle может включать его зависимости,
поэтому отчёт не приписывает символ конкретному физическому образу.
Все указатели от `dlsym` только сравниваются с NULL, не приводятся к callable типу
и не вызываются. `dlclose` балансирует только собственный успешный `dlopen`.
Наличие `RTLD_NOLOAD` исключает намеренную загрузку нового приватного образа.

Если образ не загружен, его символы отмечаются `notChecked`. Если имя не видно,
результат — `notVisible`, а не вывод об отсутствии функции в ОС. Shared cache,
ограничения загрузчика, симулятор и видимость экспортов могут влиять на результат.

## Границы и выводы

Нет XPC-запросов, изменения App Group, symlink, потребления extensions,
перебора inode, чтения системных каталогов или записи за пределами каталога
отчётов приложения. Публичный метод получения App Group проверяется только
через selector, без получения контейнера.

Наличие приватных API не означает разрешение их использования при публикации
в App Store. Этот проект предназначен для локальных исследовательских сборок.

Статус уязвимости неизменно `notTested`. Даже успешная компиляция, установка,
числовое совпадение версии и видимые символы не дают оснований заявлять об
эксплуатации. Отчёт физического устройства будет подтверждать только сделанные
наблюдения, поскольку операции эксплуатации отсутствуют.
